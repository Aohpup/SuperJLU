# SuperJLU 微信小程序（实验版）

使用 JavaScript、WXML、WXSS 实现的原生微信小程序，独立放在本目录，不改变仓库现有 Windows / Android 应用。包含首页、周课表、成绩与绩点、考试、培养方案、校园链接、通知、空教室、个人设置、隐私说明、认证和手机浏览器同步，共 12 个页面。

**默认使用手机浏览器辅助同步**：本人在 Safari 的学校教务页登录，运行本地同步书签，复制本次结果，回小程序预览并确认导入。学校查询在手机浏览器中完成，之后可在小程序离线查看，不需要电脑常开或自建云服务器。再次获取新数据需要重复读取和导入，不会后台自动同步。

## 运行

1. 在微信开发者工具中导入本目录 `wechat/`，不要导入整个上游仓库。
2. 将 `project.config.json` 的 `appid` 从 `touristappid` 改为自己的小程序 AppID；访客模式可先查看本地页面。
3. 保持 `miniprogram/config.js` 的 `transport: 'browser'`，点击编译。默认配置不进行微信登录或后端请求。
4. 真实数据入口为「我的 → 手机浏览器同步」。首次操作按下方说明设置 Safari 书签。
5. 可在「我的」切换明确标记的虚构演示数据。演示数据和本人导入数据分别存储。

AppSecret 只可配置在可选后端，不可写入小程序或提交到仓库。更改 AppID 后，提交 PR 前请恢复占位值。

## 手机读取与导入

1. 手机连接能访问教务系统的校园网络，Safari 打开 [学校课表页](https://iedu.jlu.edu.cn/jwapp/sys/wdkb/*default/index.do)，本人完成学校认证，直到看到学校自己的课表页面。
2. 将学校页面添加为 Safari 书签，命名为「同步到 SuperJLU」。在小程序同步页点击「复制同步书签脚本」，回 Safari 编辑书签，将网址完整替换为剪贴板中的 `javascript:` 内容并保存。请编辑书签网址，不要粘贴到搜索框。
3. 停留在已登录的学校课表页，运行书签，保持 Safari 在前台。它会读取课表，并尝试读取成绩、考试、校历与学业信息，在窗口中展示结果和失败模块。
4. 点击「复制本次结果」，回小程序点击「粘贴本次同步结果」，核对学期、时间、课程条数及示例，同意本机保存后确认导入。
5. 点击「查看课表」。以后数据变化时，从第 3 步重新读取；结果须在 30 分钟内导入。导入后可主动清空剪贴板。

每次导入整体替换此前账号的教务数据及计算选择；本次失败的模块保持空白，不混用旧账号缓存。只有课表读取成功的结果允许导入。数据来自本人浏览器，不能作为学校签名或正式成绩证明。

## 支持范围

| 能力 | 当前状态 |
| --- | --- |
| iPhone Safari 读取、复制、小程序确认导入及真实课表展示 | 已由使用者实机确认 |
| 成绩、考试、学业、校历映射及失败模块处理 | 有协议和模拟响应测试，尚未逐项完成实机验收 |
| 本地缓存、周课表、成绩计算、演示模式 | 已实现并有自动测试 |
| 安卓浏览器书签操作 | 尚未实机验证 |
| 手机浏览器模式下的实时空教室和通知查询 | 不支持；需另行配置连接方式 |
| 小程序直连、云端组合连接、云端学校查询 | 保留试验适配，受学校网络和页面校验限制，不保证可用 |
| 微信平台审核、正式发布 | 本源码不代表已获审核通过 |

小程序原生请求曾遇到学校页面校验 `#E2140100001 / 非法的页面跳转`，云端查询亦受网络限制。因此默认方案在学校自己的浏览器会话中查询，不尝试绕过学校校验。浏览器同步仍要求手机能正常访问并登录学校网站。

## 目录

```text
miniprogram/       原生页面、业务计算、配置、数据校验与本机缓存
phone-browser/    在学校页面运行的同步书签源代码
server/           可选后端及固定版本的上游 Python 模块
scripts/          静态检查、书签及资源生成、安全打包
tests/            Node 测试与合成响应样例
docs/backend.md   可选后端配置和连接限制
```

默认模式无前端 npm 依赖。开发检查使用 Node.js 22.8+（CI 使用 24）；可选后端使用 Python 3.10+（CI 使用 3.12）。

```sh
cd wechat
npm test
npm run check
python -m pip install -r server/requirements.txt
python -m unittest discover -s server -p 'test_*.py'
```

修改 `phone-browser/sync.js`、教务映射或学业工具后，运行 `node scripts/build-phone-bookmark.js`，一并提交生成的 `miniprogram/data/phone-bookmark.js`。`python scripts/build_tpass_constants.py` 可从固定上游模块重建 DES 表和合成向量。`prepare_assets.py` 仅用于重建演示资源，需 Pillow。

仓库根目录的 pytest 不收集本目录后端测试：后端会切换 vendored 模块存储绑定，必须用上述 unittest 命令在独立进程运行，避免影响上游测试。微信开发者工具编译和真实设备校验仍需自行进行，模拟测试不能替代学校实际登录。

`python scripts/package.py` 在忽略的 `artifacts/` 中生成源码包和可选后端部署包，排除 `.env`、`project.private.config.json`、运行缓存和依赖目录。

## 数据与许可

默认同步书签仅访问 `https://iedu.jlu.edu.cn/jwapp/sys/`，不加载远程脚本、不读取或导出 Cookie、密码、验证码，不将结果上传自建云端。小程序只在点击粘贴后读取剪贴板，只解析 JSON 并按字段白名单导入，拒绝超大、过期及不合法数据；它不会执行导入文本。业务缓存未额外加密，剪贴板结果也包含个人课表等信息，可在导入后清除。

「我的 → 清除本地教务缓存」删除本设备业务数据。连接方式改为后端时的凭据流向、存储及清除方式见 [后端说明](docs/backend.md) 和小程序隐私页。

遵循仓库 MIT 许可；固定上游快照和第三方成绩计算许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)、`server/vendor/LICENSE` 及 `server/vendor/UPSTREAM.json`。第三方模块保留原始内容，微信适配放在 vendor 目录之外。
