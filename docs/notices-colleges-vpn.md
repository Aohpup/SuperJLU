# 通知学院源与 VPN 登录（v1.0.9 起）

## 已实现

- **学院目录** `jlu_toolkit/data/college_catalog.json`：按大类收录吉林大学各学院官网；可抓取栏目目前仅 **软件学院 / 计算机学院**（博达站群列表页）。
- **首次进入通知页**：轻量「选你的学院」卡片；可跳过。偏好保存在本机 `oa_source_prefs.json`。
- **顶部快捷栏**：按偏好显示已启用信息源；可用 ‹ › 调整顺序，＋ 增减学院。
- **校内通知（OA）** 始终可选用；学院官网免登录只取列表第 1 页（与原先一致）。
- **不可抓取学院**：加入后以「官网」入口显示，提示用户打开官网查看通知公告（不假装有列表）。
- **登录网络失败**：若统一认证/教务连不上（超时、DNS、连接中断），登录框显示「先连校园 VPN 再重试」，并链到 `https://vpn.jlu.edu.cn/`。**不会**代填 VPN 账号，也未实现 HTTP 代理隧道。
