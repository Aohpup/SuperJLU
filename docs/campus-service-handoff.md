# 校园服务：会话与浏览器免登

校园服务卡片展示两种独立信息：应用内保存的会话，以及最近一次向外部浏览器发起免登跳转的结果。保存会话不证明它当前有效，也不证明外部浏览器已登录。

## 交互

- 卡片操作区在同一行统一靠底；手机自适应高度、允许窄屏按钮换行。保留完整登录说明。
- 本地状态时间兼容 Unix 秒、毫秒及 ISO 字符串；无效时间不展示。
- 首次进入读取本地状态，再次进入有 30 秒读取间隔；回到窗口或应用可见时重新读取。并发读取复用同一请求，读取失败保留原卡片。
- “刷新状态”只访问本地 API，不向学校发送请求。“验证应用内教务会话”由用户明确触发，访问学校只读入口；不验证外部浏览器。
- 教务的本地会话与学在吉大的登录结果分别处理。学在吉大不再从教务继承已登录状态。学在吉大、选课和图书馆均不显示程序无法可靠验证的浏览器登录徽标；教务使用“登录状态已保存”，附“用于程序内同步；打开网页时尝试免登”。
- 经用户实测，学在吉大不需要校园网或 VPN：显示正常打开入口，移除网络限制标识与 VPN 入口，并忽略旧覆盖配置中遗留的强制 VPN 设置。教务的校内直连要求不变。
- 直接与 WebVPN 入口均保留，当前应用连接方式只影响主次按钮样式，不会自动切换连接方式。

## 直接免登

`sso.issue_ticket` 使用应用保存的 CAS 会话向学校请求一次性 service ticket。CAS 请求明确使用直连客户端，不继承应用的 WebVPN 路由。教务以门户入口作为 service，学在吉大以已知统一认证入口作为 service，WebVPN 使用学校公开登录回调。

请求不跟随带票据的回调：票据必须交给浏览器兑换，由学校在浏览器建立自己的会话。仅接受与请求 service 的 scheme、主机、路径和既有查询参数一致的回调。

票据只出现在 302 Location，不放进 API JSON、错误页面或状态文件。应用 Cookie 和本地授权令牌不导出给浏览器。安卓的本地免登链接在已授权 WebView 中导航，由现有原生 URL 处理器把外部 HTTPS 回跳交给系统浏览器；不将本地令牌加入外部链接。

## 校外 WebVPN

应用内 VPN Cookie 无法证明外部浏览器的 VPN 会话。公共入口的匿名探测本次发生网络中断，尚不能验证学校是否支持携带目标地址的自动连续回跳，因此没有猜测或依赖该参数。

正常点击“经 WebVPN 打开”会直接获取目标票据并跳转到学校目标地址，不先显示说明页；这不代表程序已经验证外部浏览器的 VPN 状态。尚未登录时，可能由学校转入浏览器 VPN 登录页。

校园 VPN 卡片另有可选的“浏览器 VPN 登录说明”，只在用户主动查看时显示两步流程：

1. 用户点击“连接浏览器 WebVPN”，用 CAS 为学校 WebVPN service 申请新票据，交给浏览器。若学校要求认证，用户在学校页面完成。
2. 用户回到说明页，在同一个浏览器中继续打开目标服务。此时才申请目标网站的新票据，再将带票据的回调转换为 WebVPN 地址。缴费网站仍需独立账号登录，不伪装成支持 CAS 的站点。

用户已在浏览器登录 VPN 时，直接使用服务卡片的正常入口即可。兼容旧链接中的 `stage=start`，同样直接打开目标，不再强制进入说明页。不通过后台访问消费浏览器票据，不注入 Cookie，不复制持久凭据，也不猜测浏览器登录是否成功。

## 失败反馈

没有 CAS 会话、明确认证过期、网络失败、未返回匹配票据分别处理。失败显示本地说明页，提供重试、网站独立登录与返回校园服务；不会静默退回普通网页。

`browser-handoff.json` 只保存站点、连接方式、结果枚举和时间，不保存 URL、票据、Cookie 或调试异常。成功取票只记录“已发起免登跳转”，不把它当作网页登录状态，失败不删除教务会话或本地课程数据。CAS 明确失效时只更新 CAS 状态。

## 验证与需实机确认的边界

2026-10-25 最终本地验证：580 项 pytest 全部通过；独立 Node 脚本及页面脚本语法检查通过。安卓 `assembleDebug`、`lintDebug` 与 2 项 ExportProvider 原生测试通过。测试包版本为 `1.2.6-services.32`，已核对包名、签名、打包 Python 模块与服务配置和当前源码一致，未包含真实账号、会话、成绩缓存或本地接口令牌。

- 自动测试覆盖：新鲜票据、service 精确匹配、回调不被后台消费、VPN 分步取票及目标转换、独立登录站点、失败页面、仅含非秘密的状态记录、本地授权门禁、学在吉大状态独立、日期兼容、读取去重与失败恢复。
- 浏览器验证：电脑同一行按钮对齐；390px / 320px 页面无整体横向溢出；完整登录说明保留；深色样式复用现有设计变量。
- APK 使用与正式包不同的 `.local` applicationId 和 provider authority，供手动复测。
- 仍须使用学校真实认证确认：校园网教务，以及普通网络下学在吉大实际登录结果；校外同一浏览器中登录 WebVPN 后直接打开目标；会话过期时的学校返回；手机默认浏览器回跳。单元测试和模拟取票不代表上述实网验收已经完成。

用户后续实测反馈网页登录可以正常完成。已去掉学在吉大的“浏览器待验证”标签，并用普通语言解释教务保存状态的用途；手机上的最终登录回跳仍需实机确认。
